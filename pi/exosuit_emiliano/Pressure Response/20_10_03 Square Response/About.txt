			SQUARE WAVE PRESSURE RESPONSE

This folder contains the codes and data collected for a square wave pressure input.The desired pressure for the top of the square wave was changed between trials, and controlled with valves. The source pressure for inflation was set to 40psi for all tests. Each actuator had one port for inflation and one port for deflation to the vacuum. The pressure sensor was placed on the vacuum exhaust line. Note: this introduced some noise in the deflation presssure reading.

The data has the following structure for each column:
	 [ time    pressure    binary_signal_inflation    binary_signal deflation ]


		DATA FILES COLLECTED:

Hip Data - Black Vacuum:
	- data_hip_25psi.txt = 25psi. 1 Hip actuator. Black Vacuum.
	- data_hip_20psi.txt = 20 psi. " "
	- data_hip_15psi.txt = 15 psi. " "

Knee Data - 2 actuators:
