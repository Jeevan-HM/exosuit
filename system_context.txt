SYSTEM
This project studies a pneumatic knee exosuit using thigh/shank IMUs and four EMG channels: VL, RF, BF, ST. run_protocol.py starts the selected experiment mode: RL, heuristic baseline, or data collection only.

LIVE FLOW
multi_udp_v2.py receives the IMUs and computes knee angle. emg_novicon.py acquires EMG. nogrf_gaittiming.py uses AdaptiveGaitController from Gaitestimator_v2.py to estimate gait events and assemble summaries. main_RL_online.py sends timing actions to nogrf_pressure_commands.py. visualizer.py displays gait information.

RL INPUT AND OUTPUT
The incoming summary has three landmark phase fractions, stance/swing peak knee angles, four processed EMG features, and stride duration.
The actor state uses the first five features: phase fractions normalized over [0.05,0.20], [0.21,0.41], [0.50,0.70], then angles converted from degrees to radians.
Four actor outputs in [-1,1] map to stride fractions [0.05,0.20], [0.21,0.41], [0.50,0.70], [0.90,1.00]. Multiplication by stride duration gives switching times in seconds.
Gait summaries use the least-variable four cycles from each block of five. The current normal online loop completes 52 samples.
Cost = timing_error + 0.25*action_error + 0.25*kinematic_error + 0.5*(sum of four EMG features)^2. The first three errors are sums of squares. Timing targets: 0.13, 0.37, 0.68; angle targets: 0.248, 1.07 radians.

CURRENT VERSION DETAILS
The RL pressure controller resets on a fixed 1.27-second timer; its heel-strike reset is commented out. The heuristic controller uses heel-strike flags. Their active command magnitudes differ: 10 versus 5. Physical pressure units require the receiving-controller configuration.
Online EMG processing uses 20-450 Hz causal filtering and calibration scaling. MATLAB emg_processing.m uses 100-400 Hz zero-phase filtering. Keep these measures distinct.
